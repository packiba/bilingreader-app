# Исправления стабильности iPad / iOS

В этой версии внесены изменения в исходный код приложения.

## Что изменено

- `PairRow.tsx`
  - Свайп больше не выполняется по аварийному таймеру, пока палец может оставаться на экране.
  - Действие применяется только для соответствующего `pointerId` при `pointerup`.
  - `pointercancel` отменяет незавершённый свайп, а не меняет прогресс чтения.
  - Временное состояние жеста очищается при размонтировании виртуализированной строки.
  - Обработка основного pointer и кнопки озвучки проверяет идентификатор указателя.

- `MeasurePass.tsx`
  - Размер пачки измерения уменьшен до 100 строк.
  - Между пачками используется `requestAnimationFrame`, чтобы браузер мог отрисовать кадр и обработать ввод.

- `ReaderList.tsx`
  - Позднее завершение измерения больше не возвращает пользователя к старой позиции, если он успел прокрутить список во время измерения.
  - Последний видимый индекс синхронно запоминается до следующего animation frame — это уменьшает риск потери позиции при быстром уходе приложения в фон.
  - Убран фиксированный период блокировки сохранения на 2,5 секунды после открытия книги; начальная программная прокрутка по-прежнему фильтруется коротким suppress-периодом.

- `ReaderProvider.tsx`
  - Позиция чтения, известная `ReaderList`, сохраняется в отдельном ref до следующего React render.
  - Сохранение имеет debounce 500 мс и максимальный интервал 1000 мс, поэтому длительная прокрутка не откладывает запись бесконечно.
  - При `pagehide` / `visibilitychange` записывается последняя синхронно известная позиция.
  - Прогресс при открытии нормализуется: некорректные индексы и исключения не могут открыть книгу на `NaN` или за пределами книги.

- `db.ts`
  - Повторное открытие IndexedDB выполняется только для ошибок, похожих на проблему соединения/таймаут, а не для любых ошибок транзакции.

## Сборка

После распаковки проекта выполните в папке `pwa`:

```bash
npm ci
npm run build
```

Команда `npm run build` заново создаст `dist`. Папка `dist` не включена в этот архив, чтобы случайно не развернуть старую сборку вместо обновлённого исходного кода.

## Проверка

Изменённые TypeScript/TSX-файлы прошли синтаксическую транспиляцию. Полную сборку `tsc + vite build` в среде подготовки выполнить не удалось: установка npm-зависимостей не завершилась из-за недоступности пакета в npm registry. Физическое тестирование на iPad также ещё требуется.

# Проверка надёжности (ноябрь 2026)

Дизайн не менялся. Исправлено:

- **Позиция чтения после перезапуска** (`ReaderList.tsx`). После замены примерных высот строк на измеренные список оставался на том же пиксельном смещении, а это уже другая строка. Подстройка позиции почти всегда пропускалась, и неверная позиция потом сохранялась. Пример на реальной книге: было 1690, после перезапуска 4581. Теперь после измерения список привязывается к строке, которая была вверху экрана.
- **«Следующая глава» застревала**, если у главы нет пар (например, у заголовка части). Повторяющиеся начала глав убраны (`bookParser.ts`).
- **«Открываю…» висела навсегда**, если книга импортировалась, но не открылась (`ReaderProvider.tsx`).
- **Зависание IndexedDB на iOS**: у транзакций теперь есть таймаут 15 с и одна повторная попытка через новое соединение. Раньше библиотека могла остаться пустой, а «Загрузка…» крутилась бесконечно (`db.ts`).
- **Память**: библиотека больше не загружает разом полный текст всех книг, записи читаются курсором по одной (`db.ts`).
- **Озвучка**: если браузер не прислал событие окончания, строка считается дочитанной, и непрерывное чтение не зависает. Звук останавливается при закрытии, удалении или смене книги (`tts.ts`, `ReaderProvider.tsx`).
- **Перевод**: у каждого сервиса свой таймаут 5 с. Раньше зависший Google съедал всё время, и до запасных сервисов дело не доходило (`translate.ts`).
- **Защита от белого экрана** (`ErrorBoundary.tsx`): при ошибке отрисовки показывается кнопка «Перезапустить», а книга, на которой произошёл сбой, не открывается автоматически при следующем запуске.
- Удаление книги спрашивает подтверждение. Вместе с книгой удаляется её прогресс в IndexedDB. Ошибки удаления показываются пользователю.
- Битый файл (`[1, null]`) или файл без пар даёт понятное сообщение вместо TypeError или пустой читалки.
- Повреждённые настройки в localStorage больше не дают font-size NaN.
- Если при запуске не удалось открыть последнюю книгу, приложение тихо остаётся в библиотеке.
- Одновременные открытия книг (автооткрытие при запуске и тап) больше не мешают друг другу.
- Приложение запрашивает `navigator.storage.persist()`, чтобы браузер не удалял книги при нехватке места.

`dist` пересобран из исправленных исходников. В прежнем архиве `dist` был старой сборкой от 16.10 без исправлений из этого файла.
