# Biling Reader PWA

Веб-версия приложения для чтения параллельных текстов на любой паре языков, порт
Android-приложения из корня этого репозитория. Устанавливается на iPad как
PWA и работает офлайн.

## Запуск локально

```bash
cd pwa
npm install
npm run dev        # http://localhost:5173/bilingreader-app/
```

## Сборка

```bash
npm run build      # tsc + vite, результат в pwa/dist
npm run preview    # посмотреть собранное
```

## Как пользоваться на iPad

1. Откройте адрес приложения (GitHub Pages) в Safari.
2. «Поделиться» (квадрат со стрелкой) → «На главный экран».
3. Откройте приложение с иконки — оно запускается в полноэкранном режиме
   и работает без сети.

Книги добавляются через «Открыть JSON-файл» (Файлы на iPad). Поддерживаются
три формата JSON:

- плоский: `[{"pair_num", "title_src", "title_tgt", "pairs": [{"src","tgt"}]}]`
- устаревший плоский: `src_sents` / `tgt_sents` по индексам
- вложенный: дерево с `type` / `children`, листья с `pairs`

## Языки книги

Языки задаются в BLB-файле, в объекте `book`:

```json
{ "book": { "title_src": "...", "title_tgt": "...", "author": "...",
            "lang_src": "ru", "lang_tgt": "bg" },
  "chapters": [ ... ] }
```

`lang_src` — язык поля `src` каждой пары, `lang_tgt` — язык поля `tgt`. Значение —
код ISO 639-1 (`ru`, `bg`, `en`, `es`…); также понимаются `ru-RU`, `rus`,
`Russian`, `русский`. В двуязычной книге язык зашит в файл и в приложении не
меняется. Если полей нет (старый JSON-массив или BLB без них), считается `ru` / `bg`.

### Многоязычная книга (BLB v2)

В одном файле могут быть тексты на нескольких языках. В верхней панели по центру
стоит кнопка смены колонок, по бокам от неё — метки языков колонок (`ru ⇆ en`); у
многоязычной книги по метке выбирается другой язык этой колонки. Маркер озвучки
справа переключается между двумя языками на экране. Выбор запоминается для каждой книги, номера строк не меняются, поэтому
прогресс чтения сохраняется при переключении.

```json
{ "blb_version": 2, "format": "multilingual",
  "book": { "title": "...", "author": "...", "languages": ["ru", "en", "fr", "es"] },
  "cover": { ... },
  "chapters": [
    { "title": "I", "titles": { "ru": "I", "fr": "CHAPITRE I" },
      "multilingual_pairs": [ { "ru": "...", "en": "...", "fr": "...", "es": "..." } ] }
  ] }
```

Если в строке нет текста на выбранном языке, колонка остаётся пустой. Файлы
такого формата собирает проект Interlinear-translation-engine
(`multilang_sentence_aligner.py`, `create_multilang_blb.py`).

Публикация: GitHub Actions (`.github/workflows/deploy-pwa.yml`) собирает
приложение при push в `master` и выкладывает на GitHub Pages; адрес берётся из
имени репозитория (переменная `VITE_BASE`).

Книги и прогресс хранятся в IndexedDB на устройстве; настройки (тема, шрифт,
колонки) — в localStorage.

## Функции

- Непрерывный скролл пар в две колонки, шапки глав, зебра.
- Свайп строки влево = прочитано (и переход дальше), вправо = снять отметку.
- Тема, размер шрифта, перестановка колонок, разворот в одну колонку.
- Слайдер страниц с метками глав, иерархическое оглавление.
- Озвучка выбранного языка книги (Web Speech API): тап — строка, удержание —
  непрерывное чтение. Какой из двух языков книги читать — переключается кнопкой с динамиком в тулбаре.
- Перевод слова по тапу: на язык соседней колонки (тап в левой колонке —
  перевод на язык правой, и наоборот). Google gtx → MyMemory → LibreTranslate.
- Автосохранение позиции и отметок.

## Деплой на GitHub Pages

Репозиторий должен иметь remote `origin`. После первого push в GitHub:

1. Откройте Settings → Pages репозитория.
2. Source: **GitHub Actions** (если выбран вариант «Actions»).
3. Триггер — любой push, меняющий `pwa/**` или сам workflow.

Если предпочитаете деплой в ветку `gh-pages`, замените шаги в
`.github/workflows/deploy-pwa.yml` на `peaceiris/actions-gh-pages@v4`
с `publish_dir: pwa/dist` и `external_repository` недоступным (по умолчанию
в тот же репозиторий).

Адрес: `https://<owner>.github.io/bilingreader-app/`

> Иконки в `pwa/public/` сейчас простые заглушки — замените на фирменные,
> если нужно.
