# Biling Reader PWA

Веб-версия приложения для чтения параллельных текстов (BG/RU), порт
Android-приложения из корня этого репозитория. Устанавливается на iPad как
PWA и работает офлайн.

## Запуск локально

```bash
cd pwa
npm install
npm run dev        # http://localhost:5173/bilingreader-app/
```

## Сборка

```bash
npm run build      # tsc + vite, результат в pwa/dist
npm run preview    # посмотреть собранное
```

## Как пользоваться на iPad

1. Откройте адрес приложения (GitHub Pages) в Safari.
2. «Поделиться» (квадрат со стрелкой) → «На главный экран».
3. Откройте приложение с иконки — оно запускается в полноэкранном режиме
   и работает без сети.

Книги добавляются через «Открыть JSON-файл» (Файлы на iPad). Поддерживаются
три формата JSON:

- плоский: `[{"pair_num", "title_src", "title_tgt", "pairs": [{"src","tgt"}]}]`
- устаревший плоский: `src_sents` / `tgt_sents` по индексам
- вложенный: дерево с `type` / `children`, листья с `pairs`

Книги и прогресс хранятся в IndexedDB на устройстве; настройки (тема, шрифт,
колонки) — в localStorage.

## Функции

- Непрерывный скролл пар в две колонки, шапки глав, зебра.
- Свайп строки влево = прочитано (и переход дальше), вправо = снять отметку.
- Тема, размер шрифта, перестановка колонок, разворот в одну колонку.
- Слайдер страниц с метками глав, иерархическое оглавление.
- Озвучка болгарского текста (Web Speech API): тап — строка, удержание —
  непрерывное чтение.
- Перевод слова по тапу (MyMemory API с fallback на LibreTranslate).
- Автосохранение позиции и отметок.

## Деплой на GitHub Pages

Репозиторий должен иметь remote `origin`. После первого push в GitHub:

1. Откройте Settings → Pages репозитория.
2. Source: **GitHub Actions** (если выбран вариант «Actions»).
3. Триггер — любой push, меняющий `pwa/**` или сам workflow.

Если предпочитаете деплой в ветку `gh-pages`, замените шаги в
`.github/workflows/deploy-pwa.yml` на `peaceiris/actions-gh-pages@v4`
с `publish_dir: pwa/dist` и `external_repository` недоступным (по умолчанию
в тот же репозиторий).

Адрес: `https://<owner>.github.io/bilingreader-app/`

> Иконки в `pwa/public/` сейчас простые заглушки — замените на фирменные,
> если нужно.
